# Velix

This is the **Velix** application, a modern web app built with React, Vite, and Tailwind CSS.

## Getting Started

To get a local copy up and running, follow these simple steps.

### Prerequisites

Make sure you have [Bun](https://bun.sh/) installed on your machine.

### Installation

1. Clone the repo:

    ```sh
    git clone https://github.com/your_username/Velix.git
    ```

2. Install dependencies:

    ```sh
    bun install
    ```

## Available Scripts

In the project directory, you can run:

### `bun dev`

Runs the app in development mode.
Open [http://localhost:5173](http://localhost:5173) to view it in the browser. The page will reload if you make edits.

### `bun build`

Builds the app for production to the `dist` folder.
It correctly bundles React in production mode and optimizes the build for the best performance.

### `bun lint`

Lints the project files using ESLint to enforce code quality.

### `bun preview`

Serves the production build locally to preview it before deployment.
